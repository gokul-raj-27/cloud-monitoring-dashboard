## Project Scope

The objective of this project is to design and develop a cloud monitoring dashboard that provides a visual overview of infrastructure performance, resource utilization, network activity, requests, system health and alerts.

The dashboard provides a user-friendly interface for monitoring important cloud infrastructure metrics.

---

## Project Description

Cloud Monitoring Dashboard is a web-based monitoring interface inspired by cloud infrastructure monitoring platforms.

The dashboard displays simulated monitoring metrics such as CPU utilization, memory usage, network traffic and request counts.

It also provides visual performance charts, EC2 instance status, recent alerts and an overall system health score.

## Dashboard Metrics

The dashboard monitors the following metrics:

| Metric | Description |
|---|---|
| CPU Utilization | Displays current CPU usage |
| Memory Usage | Displays memory utilization |
| Network Traffic | Displays network traffic volume |
| Requests | Displays processed request count |
| EC2 Instances | Displays running instance information |
| System Health | Displays overall system health score |
| Alerts | Displays recent monitoring alerts |
